---
name: eval-report-workflow
description: Record reproducible evaluation measurements and judge-calibration evidence when reporting runs.
---

Keep run provenance with the evidence: dataset and source versions, model and judge,
scaffold, limits, dates, selected samples, completion/errors, tokens and measured cost.
Read these from configuration and logs, not memory. Compare with published results only
when the conditions support the comparison. State differences once where consequential.
For judge calibration, compare decisions with independently established reference labels;
report selection, denominators and uncertainty. A small or selected sample does not
establish population prevalence. The writing skill and supplied framework own report
structure. Keep execution details in linked evidence and brief analysis limitations.
