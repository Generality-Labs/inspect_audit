# Store filesystem and decision log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The store is addressed by an fsspec locator instead of a `Path`, and review decisions are an append-only log of objects folded into the `Review` the renderer already applies, so the store can move to object storage with nothing shared ever edited in place. Slice one of the portable store spec: the local directory is the only backend exercised in production; no git commit remains.

**Architecture:** `findings/fs.py` holds `StoreFS`, a thin wrapper over an fsspec filesystem and a root key; `io.py`, `export.py`, the renderer's writes, `leads.py` and the CLI go through it. `review.py` gains `Decision`, `load_decisions`, `fold`, `write_review_views` and `migrate_review_files`; `load_review` becomes the fold. `store.py` loses git and `review_dir`, gains `set_status` and `retract`, and writes one decision object per call. The CLI gains `--store` with `INSPECT_AUDIT_STORE` as default, loses `--review`, and gains `review status`, `review retract` and `review migrate`.

**Tech Stack:** Python 3.13, pydantic v2, fsspec (via inspect_ai; `memory://` for tests), PyYAML, pandas/pyarrow, pytest. Gate: `uv run pre-commit run --all-files`, `uv run basedpyright src`, `uv run pytest -q -p no:cacheprovider`.

**Spec:** `docs/superpowers/specs/2026-10-09-portable-store-design.md` (sections "The store", "Decisions as an append-only log", "The Store API", "Testing", migration steps 1 and 2).

## Global Constraints

- Python `>=3.11`; develop on 3.13. Ruff and basedpyright strict per `pyproject.toml`; no new ignores; `DTZ` rules apply.
- No new dependency: fsspec and s3fs arrive with inspect_ai.
- Runs are immutable objects; decisions are append-only objects under `review/`; everything else is derived and may be rewritten by any writer.
- Decision object key: `review/<at>-<id>.json` with `at` as `YYYYMMDDTHHMMSSZ`, so a listing is in time order.
- Authors are stored in full (`Name <email>`) in decisions; the export keeps exporting names only.
- The derived `suppressions.yaml` and `issues.yaml` start with the line `# derived from review/; do not edit`.
- `--out` keeps working as a synonym of `--store` for `run` and `summary` in this release.
- Stage new files before the gate (pre-commit skips untracked files).
- Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Branch `feat/store-fs` is stacked on `docs/portable-store` (PR #37) and targets `feat/findings`.

## Review Focus

1. Decisions written out of time order (a late writer with an earlier clock) must still fold in key order, and the listing must not depend on the backend's enumeration order. Test in Task 2 on `memory://`.
2. A retraction of a suppression must un-suppress on the next render; a retraction of an acceptance must free its fingerprints for another acceptance. Test in Task 2.
3. Two acceptances of the same fingerprint, both present in the log, must fold to the later one and produce a warning naming both decision ids. Test in Task 2.
4. `review migrate` on a store with the two YAML files must reproduce the same `Review` the files loaded before, and running it twice must write nothing the second time. Test in Task 2.
5. The same runs and decisions on a local directory and on `memory://` must render byte-identical summaries, parquet-derived frames and export documents. Test in Task 1 for runs and Task 4 for the whole render.

```python
# src/inspect_audit/findings/fs.py
"""One way to read and write a store, whether it is a directory, S3, R2 or an fsspec memory filesystem.

Keys are relative to the store root and use `/`. Listings are sorted, so no caller's output
depends on the order a backend enumerates objects.
"""

from __future__ import annotations

from pathlib import Path

import fsspec
from fsspec import AbstractFileSystem
from fsspec.core import url_to_fs


class StoreFS:
    def __init__(self, fs: AbstractFileSystem, root: str) -> None:
        self.fs = fs
        self.root = root.rstrip("/")

    @classmethod
    def from_locator(cls, locator: str | Path) -> StoreFS:
        text = str(locator)
        if "://" not in text:
            text = Path(text).expanduser().resolve().as_posix()
        fs, root = url_to_fs(text)
        return cls(fs, root)

    @property
    def locator(self) -> str:
        protocol = self.fs.protocol if isinstance(self.fs.protocol, str) else self.fs.protocol[0]
        return self.root if protocol == "file" else f"{protocol}://{self.root}"

    def key(self, *parts: str) -> str:
        return "/".join(p.strip("/") for p in parts if p)

    def _full(self, key: str) -> str:
        return f"{self.root}/{key}" if key else self.root

    def _rel(self, full: str) -> str:
        full = str(full)
        prefix = f"{self.root}/"
        return full[len(prefix):] if full.startswith(prefix) else full.rsplit(self.root, 1)[-1].lstrip("/")

    def exists(self, key: str) -> bool:
        return bool(self.fs.exists(self._full(key)))

    def is_file(self, key: str) -> bool:
        return bool(self.fs.isfile(self._full(key)))

    def read_text(self, key: str) -> str:
        return self.read_bytes(key).decode("utf-8")

    def read_bytes(self, key: str) -> bytes:
        with self.fs.open(self._full(key), "rb") as handle:
            return bytes(handle.read())

    def write_text(self, key: str, text: str) -> str:
        return self.write_bytes(key, text.encode("utf-8"))

    def write_bytes(self, key: str, data: bytes) -> str:
        full = self._full(key)
        parent = full.rsplit("/", 1)[0]
        self.fs.makedirs(parent, exist_ok=True)
        with self.fs.open(full, "wb") as handle:
            handle.write(data)
        return key

    def ls(self, prefix: str) -> list[str]:
        full = self._full(prefix)
        if not self.fs.exists(full):
            return []
        return sorted(self._rel(p) for p in self.fs.ls(full, detail=False))

    def glob(self, pattern: str) -> list[str]:
        return sorted(self._rel(p) for p in self.fs.glob(self._full(pattern)))

    def local_path(self, key: str) -> Path | None:
        protocol = self.fs.protocol if isinstance(self.fs.protocol, str) else self.fs.protocol[0]
        return Path(self._full(key)) if protocol == "file" else None


def as_store_fs(value: StoreFS | str | Path) -> StoreFS:
    return value if isinstance(value, StoreFS) else StoreFS.from_locator(value)
```

fsspec's memory filesystem keys have no leading slash issues when the root is `store-…`; the `_rel` fallback covers the local backend returning absolute paths. If `fs.ls` on the memory backend returns names with a leading `/`, normalise in `_rel` by also stripping a leading `/` before comparing with the root.

Then convert `io.py` (`write_run`, `read_run`, `read_runs`, `read_current`, `write_parquet`) to `StoreFS` and keys; `read_current` iterates `fs.glob("*/runs/*.run.json")` grouped by the first path segment; `write_parquet` uses `pyarrow`/pandas `to_parquet` into a `BytesIO` then `fs.write_bytes`. Convert `export.py` and `cli.py` as the Interfaces block says: `_run_path` builds `f"{slug_dir}/runs/{run.id}.run.json"` and loops on `fs.exists`. `leads_markdown` and `render_current` call `as_store_fs` first. Keep `_summaries_from_disk` printing the locator in messages.

```python
class Decision(BaseModel):
    """One review decision, stored as its own object under review/; the log is append-only."""

    model_config = ConfigDict(extra="forbid")
    id: str = Field(min_length=1)
    at: AwareDatetime
    author: str
    kind: Kind
    reason: str | None = None
    suppress: SuppressPayload | None = None
    accept: AcceptPayload | None = None
    link: LinkPayload | None = None
    status: StatusPayload | None = None
    retract: RetractPayload | None = None

    @model_validator(mode="after")
    def _one_payload(self) -> Decision:
        present = [k for k in ("suppress", "accept", "link", "status", "retract") if getattr(self, k) is not None]
        if present != [self.kind]:
            raise ValueError(f"a {self.kind} decision needs exactly the {self.kind} payload, got {present or 'none'}")
        return self

    def key(self) -> str:
        return f"{REVIEW_PREFIX}/{_stamp(self.at)}-{self.id}.json"


def _stamp(at: datetime) -> str:
    return at.astimezone(UTC).strftime("%Y%m%dT%H%M%SZ")


def new_decision_id(at: datetime) -> str:
    return f"dec-{_stamp(at)}-{uuid4().hex[:4]}"


def load_decisions(fs: StoreFS) -> list[Decision]:
    decisions: list[Decision] = []
    for key in fs.glob(f"{REVIEW_PREFIX}/*.json"):
        try:
            decisions.append(Decision.model_validate_json(fs.read_text(key)))
        except (ValueError, ValidationError) as ex:
            raise ValueError(f"{key}: {ex}") from ex
    return decisions  # glob is sorted, and keys sort by time then id


def write_decision(fs: StoreFS, decision: Decision) -> str:
    return fs.write_text(decision.key(), decision.model_dump_json(indent=1, exclude_none=True) + "\n")
```

The fold keeps, per decision id, what it contributed, so a retraction can undo it:

```python
class Fold(BaseModel):
    model_config = ConfigDict(extra="forbid")
    review: Review
    warnings: list[str] = Field(default_factory=list)


def fold(decisions: Sequence[Decision]) -> Fold:
    retracted = {d.retract.decision for d in decisions if d.kind == "retract" and d.retract}
    live = [d for d in sorted(decisions, key=lambda d: d.key()) if d.kind != "retract" and d.id not in retracted]
    suppressions: list[SuppressionRule] = []
    issues: dict[str, IssueEntry] = {}
    owner: dict[str, tuple[str, str]] = {}  # fingerprint -> (issue id, decision id)
    statuses: dict[str, Status] = {}
    status_provenance: dict[str, Provenance] = {}
    warnings: list[str] = []
    for d in live:
        if d.kind == "suppress" and d.suppress:
            suppressions.append(SuppressionRule(rule=d.suppress.rule, subject=d.suppress.subject, producer=d.suppress.producer,
                                                kind=d.suppress.kind, author=d.author, reason=d.reason or "", since=d.at.date()))
        elif d.kind == "accept" and d.accept:
            fingerprints = list(d.accept.fingerprints)
            for fp in list(fingerprints):
                if fp in owner:
                    previous_issue, previous_decision = owner[fp]
                    warnings.append(f"{fp} accepted by {previous_decision} ({previous_issue}) and again by {d.id} ({d.accept.issue}); the later wins")
                    issues[previous_issue] = issues[previous_issue].model_copy(update={"findings": [f for f in issues[previous_issue].findings if f != fp]})
                owner[fp] = (d.accept.issue, d.id)
            issues[d.accept.issue] = IssueEntry(id=d.accept.issue, title=d.accept.title, subject=d.accept.subject, findings=fingerprints,
                                                author=d.author, opened=d.at.date(), reason=d.reason)
        elif d.kind == "link" and d.link:
            if d.link.issue in issues:
                issues[d.link.issue] = issues[d.link.issue].model_copy(update={"github": d.link.url})
            else:
                warnings.append(f"{d.id} links unknown issue {d.link.issue}")
        elif d.kind == "status" and d.status:
            for fp in d.status.fingerprints:
                statuses[fp] = d.status.status
                status_provenance[fp] = Provenance(timestamp=d.at, author=d.author, reason=d.reason)
    issues = {k: v for k, v in issues.items() if v.findings}  # an issue emptied by a later acceptance is dropped
    review = Review(suppressions=suppressions, issues=list(issues.values()), statuses=statuses, status_provenance=status_provenance)
    return Fold(review=review, warnings=warnings)
```

`Review` gains `statuses: dict[str, Status] = Field(default_factory=dict)` and `status_provenance: dict[str, Provenance] = Field(default_factory=dict)`; its validator for shared fingerprints stays (the fold never produces them). `apply_review` applies statuses after issues: `finding.status = statuses[fp]` and `finding.history.append(StatusChange(status=…, provenance=status_provenance[fp]))`. `load_review(fs)` returns `fold(load_decisions(fs)).review`. `write_review_views` dumps the derived lists with `DERIVED_HEADER` prepended. `migrate_review_files` reads the two YAML files through `fs` (the old `_load_list` logic over `fs.read_text`), builds a suppress decision per rule (`at` = `since` at midnight UTC, `author`, `reason`), an accept decision per issue (`at` = `opened` at midnight UTC, `issue` = its id, fingerprints = its findings) and a link decision when `github` is set, with deterministic ids `dec-<stamp>-<sha1 of the payload json>[:4]`, writes any whose key does not already exist, and returns the ones written. The `SUPPRESSIONS_FILE`/`ISSUES_FILE` constants stay as the view names.

```python
class Store:
    def __init__(self, locator: StoreFS | str | Path) -> None:
        self.fs = as_store_fs(locator)

    def runs(self) -> list[Run]: return read_current(self.fs)
    def history(self) -> list[Run]: return read_runs(self.fs)
    def review(self) -> Review: return load_review(self.fs)
    def reviewed(self) -> list[Run]: return apply_review(self.runs(), self.review())
    # resolve unchanged

    def suppress(self, *, rule, author, reason, subject="*", producer=None, kind="false_positive") -> Decision:
        probe = SuppressionRule(rule=rule, subject=subject, producer=producer, kind=kind, author=author, reason=reason, since=_today())
        if not any(probe.matches(f) for run in self.runs() for f in run.findings):
            raise StoreError(...)
        return self._write(Decision(id=new_decision_id(now), at=now, author=author, kind="suppress", reason=reason,
                                    suppress=SuppressPayload(rule=rule, subject=subject, producer=producer, kind=kind)))

    def accept(self, selection, *, title, author, reason=None) -> Decision:
        review = self.review(); findings = self.resolve(selection)
        # one eval, ownership check against review.issues as today, then
        return self._write(Decision(..., kind="accept", accept=AcceptPayload(issue=_next_issue_id(review), title=title,
                                    subject=subjects[0], fingerprints=sorted({f.fingerprint for f in findings}))))

    def link(self, issue_id, url, *, author) -> Decision:
        if issue_id not in {i.id for i in self.review().issues}: raise StoreError(f"no issue {issue_id}")
        return self._write(Decision(..., kind="link", link=LinkPayload(issue=issue_id, url=url)))

    def set_status(self, selection, *, status, author, reason) -> Decision:
        findings = self.resolve(selection)
        return self._write(Decision(..., kind="status", status=StatusPayload(fingerprints=sorted({f.fingerprint for f in findings}), status=status)))

    def retract(self, decision_id, *, author, reason) -> Decision:
        if decision_id not in {d.id for d in load_decisions(self.fs)}: raise StoreError(f"unknown decision {decision_id}")
        return self._write(Decision(..., kind="retract", retract=RetractPayload(decision=decision_id)))

    def _write(self, decision: Decision) -> Decision:
        from .cli import render_current
        if not _AUTHOR.fullmatch(decision.author): raise StoreError("author must be 'Name <email>' ...")
        write_decision(self.fs, decision)
        render_current(self.fs)   # re-reads the log, writes the derived views, summaries, parquet, export
        return decision
```
